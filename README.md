# Linear Regression From Scratch

This project demonstrates how to implement Linear Regression from scratch without using Scikit-Learn.

## Features

- Data Exploration
- Data Visualization
- Gradient Descent
- Manual Cost Function
- Manual Parameter Updates
- Prediction
- Evaluation
- Regression Line
- R²
- RMSE
- MAE

## Dataset

Salary Data

## Results

R² = 0.9347

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
